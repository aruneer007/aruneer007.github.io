# Arun Venkatachalam - Portfolio

A responsive Machine Learning Engineer portfolio adapted for GitHub Pages using a Bento Grid layout.

## Live URL
Once this repository is published as `arunv.github.io`, the site will be available at:

`https://arunv.github.io/`

## Publish on GitHub Pages

1. Create a GitHub repository named exactly `arunv.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Set **Source** to `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`, then save.

## Main files

- `index.html` - portfolio content
- `main.css` - styling and responsive layout
- `script.js` - hover glow and tilt effects
- `Arun_Venkatachalam_Resume.pdf` - downloadable resume
- `preview.png` - social sharing preview image
- `.nojekyll` - tells GitHub Pages to serve the site as plain static files

## Custom domain

No `CNAME` file is included. This prevents the site from redirecting to the original author's domain. Add a `CNAME` file later only if you purchase and configure your own domain.
